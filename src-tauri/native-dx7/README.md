# Native DX7 source snapshot

MSFA is Apache-2.0; see `COPYING`. The pinned upstream commit is
`f67d41d313b7dc85f6fb99e79e515cc9d208cfff`. The source copied here is the
Tetorica standalone/live-control port in
`hello_ymfm/w/tetorica-msfa-dx7-wasm/vendor/msfa`; its `UPSTREAM.md` refers to
research files in that source repository, rather than this packaged snapshot.
No third-party voice bank is bundled.

`../src/native_genesis_dx7.cpp` uses the same scalar synthesis path and 44.1 kHz
internal rate as the shipped WASM. The Native-only `SynthUnit` extension adds:

- A fixed-slot note-on result and slot release, so performance owners and
  manual Keyboard leases can release their own overlapping notes.
- An allocation-free panic that resets gates, cached frames, controllers,
  filter and LFO without deleting the 16 preallocated `Dx7Note` objects.

The Native snapshot also supplies a standard C++ atomic fence when MSFA has
no platform memory barrier. This supports MSVC in C++17 mode, where its
upstream fallback `#warning` fails compilation, and avoids an empty barrier.
The ring buffer's full-buffer producer wait uses standard C++ `sleep_for`
instead of POSIX-only `nanosleep`, preserving its 1 ms delay on Windows too.

These additions are generated by `scripts/sync_native_dx7.py`; the remaining
snapshot is copied unchanged. Device-rate conversion is owned by the Native
adapter. Its integer-phase 44.1→48/96 kHz interpolation matches the JS adapter.
The lookup tables are initialized once, outside audio callbacks.

From the Tauri repository:

```sh
python3 scripts/sync_native_dx7.py --source ../..
python3 scripts/sync_native_dx7.py --check --source ../..
```

The manifest records hashes of both original and modified files. Do not edit
the generated snapshot directly; update the source or the explicit generator
patch, then synchronize and run the offline PCM comparison.
