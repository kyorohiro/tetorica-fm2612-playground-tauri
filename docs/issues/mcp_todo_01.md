目的：
Playground の画面から指示を入力し、既存の ChatGPT がその指示を受け取って、現在の MCP ツールでプロジェクトを編集できるようにすることです。画面を切り替える手間を減らしたいです。

1. Playground の入力欄に「ベースを追加して」などと入力する。
2. 接続済みの ChatGPT にメッセージが届く。
3. ChatGPT が現在のプロジェクトを MCP 経由で読み取る。
4. ChatGPT が MCP 経由でファイルを編集する。
5. Playground のエディターに変更が反映される。

制約：
- Tauri アプリを維持する。
- OpenCode などの別エージェントを起動する構成にはしない。
- Copilot SDK を前提にしない。
- 新しい AI チャットサービスを一から作る方向には広げない。
- 既存の MCP と ChatGPT の実行環境を利用する。
- ChatGPT の UI 自動操作や非公開 API に依存しない。
- 最初はメッセージ送信と編集反映を優先する。
- 自動再生や自動保存は今回の対象にしない。
